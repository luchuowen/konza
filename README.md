# Konza Elevators & Escalator Co. Ltd — Website

A premium marketing and lead-generation website for Konza Elevators &
Escalator Co. Ltd, a Nairobi elevator/escalator installer founded in 2013 and
Kenya's authorized Fuji Elevator distributor. This is a full rebuild of
`konzaelevators.co.ke`, built by NAVAC GLOBAL on the "Vertical City" design
system. See `docs/BLUEPRINT.md` for the full vision, non-negotiables, and
what this project is not.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
